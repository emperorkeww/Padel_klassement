# Nieuw webproject

Lege startstructuur, klaar om opnieuw te beginnen.

## Structuur

```
index.html          startpagina (blanco boilerplate)
css/styles.css      stijlen
js/main.js          entry point
assets/             afbeeldingen / fonts / statische bestanden
docs/               documentatie
supabase/           database (migrations, config)
  migrations/       SQL-migraties
```

## Aan de slag

Open `index.html` in de browser, of start een lokale server:

```
python3 -m http.server 8000
```
